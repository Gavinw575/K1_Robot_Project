Week 6 — Voice Control Pipeline

Learning Objectives
  • Capture audio from the K1's 6-channel microphone array via sounddevice/ffmpeg
  • Transcribe speech to text using the Whisper model
  • Parse natural language commands using the Groq LLM API
  • Synthesize speech responses using Piper TTS
  • Integrate the full pipeline: voice-in → command → robot action → voice-out

1. Pipeline Overview

The voice control pipeline has four stages: 

Microphone Audio
      |
      v
[Whisper STT]  ←— transcribes spoken words to text
      |
      v
[Groq LLM]     ←— parses intent: COMMAND or REPLY
      |
      v
[Robot Action] ←— executes walk, turn, stop, etc.
      |
      v
[Piper TTS]    ←— speaks a confirmation back

2. Speech to Text: Whisper

OpenAI Whisper is an open-weight ASR (automatic speech recognition) model that runs entirely locally — no internet required during inference.

3. Audio Capture from the Robot's 6-Channel Mic

The K1's NationalChip 6-channel microphone array appears as an ALSA device. We use ffmpeg to mix all 6 channels down to mono before Whisper: 

# List audio capture devices on the robot
arecord -l

# Capture 3 seconds, mix 6 ch → mono, output 16 kHz WAV
ffmpeg -f alsa -ac 6 -ar 48000 -i hw:0,0 \
       -ac 1 -ar 16000 -t 3 /tmp/voice_input.wav -y

# Or use sounddevice in Python for in-process capture
import sounddevice as sd
import numpy as np

def record_mono(duration_s=3, fs=16000):
    audio = sd.rec(int(duration_s * fs),
                   samplerate=fs, channels=6, dtype="float32")
    sd.wait()
    return audio.mean(axis=1)   # mix 6 channels to mono

4. LLM Command Parsing with Groq

Groq provides fast LLM inference (Llama3-8b at ~800 tokens/s) with a free API tier — perfect for real-time command parsing with sub-second latency. 

import os
from groq import Groq

client = Groq(api_key=os.environ["GROQ_API_KEY"])

SYSTEM_PROMPT = """
You are a command parser for a humanoid robot named K1.
The user will speak a command in natural language.
You must respond with EXACTLY one line in this format:

COMMAND:<action>:<param>
or
REPLY:<spoken response>

Valid actions: walk_forward, walk_backward, turn_left, turn_right,
               stop, sit, stand, wave, bow

Examples:
  User: "walk forward two meters"   → COMMAND:walk_forward:2.0
  User: "what is your name?"        → REPLY:My name is K1.
  User: "turn right 90 degrees"     → COMMAND:turn_right:1.5708
"""

def parse_command(transcript: str) -> tuple[str, str]:
    resp = client.chat.completions.create(
        model="llama3-8b-8192",
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user",   "content": transcript}
        ],
        temperature=0.0,
        max_tokens=64
    )
    line = resp.choices[0].message.content.strip()
    parts = line.split(":", 2)
    return parts[0], parts[1] if len(parts) > 1 else line

5. Text to Speech: Piper TTS

Piper is a fast, local neural TTS engine. The danny-low voice model produces natural-sounding male English speech at low latency. 

# Install Piper
pip install piper-tts

# Download the danny-low voice model
python3 -m piper.download --model en_US-danny-low

# Synthesize speech from text
from piper.voice import PiperVoice
import sounddevice as sd

voice = PiperVoice.load("en_US-danny-low.onnx")

def speak(text: str):
    audio_bytes = bytes()
    for chunk in voice.synthesize_stream_raw(text):
        audio_bytes += chunk
    import numpy as np
    audio = np.frombuffer(audio_bytes, dtype=np.int16)
    sd.play(audio, samplerate=22050)
    sd.wait()

6. Complete Pipeline Integration

import time, whisper, sounddevice as sd
import booster_robotics_sdk as sdk
# (imports from above sections...)

def execute_command(action: str, param: str, client):
    """Dispatch parsed robot actions."""
    if action == "walk_forward":
        dist = float(param)
        t = dist / 0.3
        t_end = time.time() + t
        while time.time() < t_end:
            client.Move(0.3, 0, 0); time.sleep(0.02)
    elif action == "turn_left":
        rad = float(param)
        t = rad / 0.4
        t_end = time.time() + t
        while time.time() < t_end:
            client.Move(0, 0, 0.4); time.sleep(0.02)
    elif action == "stop":
        client.Move(0, 0, 0)
    client.Move(0, 0, 0)   # halt after command

def voice_loop(loco_client):
    stt_model = whisper.load_model("base")
    print("Voice pipeline ready. Speak a command...")
    while True:
        audio = record_mono(3)
        if audio.max() < 0.01:       # silence detected
            print("[silence — waiting]")
            continue
        text = stt_model.transcribe(audio, language="en")["text"]
        print(f"Heard: {text}")
        intent, param = parse_command(text)
        if intent == "COMMAND":
            speak(f"Executing {param}")
            execute_command(param, "", loco_client)
        else:
            speak(param)

7. PulseAudio vs ALSA on the Robot

Ubuntu 22.04 on the Jetson uses PulseAudio by default. Piper TTS and sounddevice may conflict if PulseAudio occupies the ALSA device: 

# Check if PulseAudio is running
pulseaudio --check && echo "PulseAudio running"

# Option A: use PulseAudio backend (recommended)
export PIPER_AUDIO_BACKEND=pulseaudio

# Option B: stop PulseAudio and use ALSA directly (may cause issues with other apps)
pulseaudio -k
# Then run your audio scripts

# Option C: use pacmd to route to a specific sink
pacmd list-sinks
