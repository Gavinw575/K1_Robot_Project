1. URDF — Unified Robot Description Format

A URDF (Unified Robot Description Format) file is an XML document that describes a robot's physical structure: its links (rigid bodies), joints (how links connect and move), and appearance (mesh files).

1.1 Key Elements

Element Description
<link> A rigid body segment. Contains visual mesh, collision geometry, and inertial properties.
<joint> Connects two links. Defines motion type (revolute, prismatic, fixed, etc.) and axis of motion.
<origin> Position (xyz) and rotation (rpy — roll, pitch, yaw) of a link or joint relative to its parent.
<mesh> STL or DAE 3-D model file for visual rendering in RViz2.

1.2 Joint Types Explained

  • revolute — rotates around one axis within specified limits (most K1 joints)
  • continuous — rotates around one axis with no limits (wheels)
  • prismatic — slides along one axis (linear actuators)
  • fixed — no movement; welds two links together (chassis, camera mount)
  • floating — 6-DOF free movement (used for the root/base link of floating-base robots)
<!-- Excerpt from K1 URDF: left elbow revolute joint -->
<joint name="left_elbow_joint" type="revolute">
  <parent link="left_upper_arm_link"/>
  <child  link="left_lower_arm_link"/>
  <origin xyz="0 0 -0.28" rpy="0 0 0"/>
  <axis xyz="0 1 0"/>
  <limit lower="-2.09" upper="0.0"
         effort="30" velocity="10"/>
</joint>

2. RViz2 Setup with the K1 Model

2.1 Launch robot_state_publisher

robot_state_publisher reads the URDF and the live /joint_states topic to broadcast /tf transforms for every link. RViz2 uses those transforms to render the model in the correct pose. 

# On the robot — start robot_state_publisher with the K1 URDF
ros2 run robot_state_publisher robot_state_publisher \
    --ros-args -p robot_description:="$(xacro ~/k1_description/urdf/k1.urdf.xacro)"

2.2 Launch RViz2 and Configure the Display

  1. On your laptop, run rviz2.
  2. In the Global Options panel (top-left), set Fixed Frame to trunk_link.
  3. Click Add → By display type → RobotModel.
  4. In the RobotModel panel, set Description Topic to /robot_description.
  5. Click Add → TF to see all coordinate frames.
  6. Save your config: File → Save Config As → k1.rviz.

3. Camera Feed via HTTP Bridge

The K1's stereo camera publishes compressed images to /booster_video_stream. The robot_video_bridge.py script subscribes to that topic and re-serves the frames as a MJPEG HTTP stream on port 8080 — viewable in any browser or OpenCV program.

3.1 Start the Video Bridge (on the robot)

# Run the HTTP video bridge on the robot
python3 ~/booster_robotics_sdk/scripts/robot_video_bridge.py \
    --port 8080 \
    --topic /booster_video_stream

3.2 View the Camera Feed

# On your laptop — open the stream in a browser
# Navigate to:  http://192.168.10.102:8080

# Or use the provided viewer script
python3 ~/booster_robotics_sdk/scripts/view_camera.py \
    --host 192.168.10.102 \
    --port 8080

4. Adding a Custom Marker in RViz2

RViz2 Markers let you draw arbitrary shapes (arrows, spheres, text) in the 3-D scene from Python. This is useful for debugging — e.g., showing where the robot thinks a ball is. 

import rclpy
from rclpy.node import Node
from visualization_msgs.msg import Marker

class MarkerPublisher(Node):
    def __init__(self):
        super().__init__('marker_publisher')
        self.pub = self.create_publisher(Marker, '/visualization_marker', 10)
        self.create_timer(1.0, self.publish_marker)

    def publish_marker(self):
        m = Marker()
        m.header.frame_id = 'trunk_link'
        m.header.stamp = self.get_clock().now().to_msg()
        m.ns = 'demo'; m.id = 0
        m.type = Marker.SPHERE
        m.action = Marker.ADD
        m.pose.position.x = 1.0   # 1 m in front
        m.pose.position.z = 0.5
        m.scale.x = m.scale.y = m.scale.z = 0.2
        m.color.r = 1.0; m.color.g = 0.0
        m.color.b = 0.0; m.color.a = 1.0
        self.pub.publish(m)

def main():
    rclpy.init()
    rclpy.spin(MarkerPublisher())

if __name__ == '__main__':
    main()
  1. Save the script above as marker_demo.py.
  2. In RViz2 click Add → By topic → /visualization_marker → Marker.
  3. Run the script: python3 marker_demo.py
  4. A red sphere should appear 1 m in front of the robot in RViz2.
