1. Object Detection Fundamentals

1.1 Bounding Boxes

A bounding box (bbox) is an axis-aligned rectangle that encloses a detected object. It is represented as (x_center, y_center, width, height) in YOLO format, all normalised to [0, 1] relative to the image size.

1.2 Confidence Score

Each detection comes with a confidence score between 0 and 1 — the model's estimate of how likely it is that (a) an object exists in the box, and (b) the predicted class is correct. Detections below a threshold (typically 0.4–0.5) are discarded.

1.3 IoU — Intersection over Union

IoU measures the overlap between a predicted box and a ground-truth box. A value of 1.0 means perfect alignment; 0 means no overlap. During Non-Maximum Suppression (NMS) YOLO removes duplicate boxes with IoU above a threshold (typically 0.45).

2. YOLOv8 Architecture Overview

YOLOv8 (Ultralytics, 2023) is a single-stage detector with three parts:

  • Backbone (CSPDarknet) — extracts feature maps at multiple scales from the input image.
  • Neck (PAN-FPN) — combines feature maps across scales so both large and small objects are detected well.
  • Head — predicts bounding boxes, objectness, and class probabilities for each grid cell at each scale.

The yolov8n (nano) variant has only 3.2 M parameters and runs at >30 FPS on a laptop CPU — suitable for real-time use on the K1.

3. Subscribing to the Camera Topic and Running Inference

The K1 publishes compressed JPEG frames on /booster_video_stream (type sensor_msgs/CompressedImage). The script below subscribes, decodes each frame, runs YOLOv8, and republishes the annotated image. 

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import CompressedImage
import cv2
import numpy as np
from ultralytics import YOLO

MODEL = YOLO("yolov8n.pt")          # downloads on first run
CONF_THRESH = 0.45

class YoloDetector(Node):
    def __init__(self):
        super().__init__("yolo_detector")
        self.sub = self.create_subscription(
            CompressedImage,
            "/booster_video_stream",
            self.callback,
            10
        )
        self.pub = self.create_publisher(
            CompressedImage, "/yolo_laptop_vis", 10
        )
        self.frame_count = 0
        self.t0 = self.get_clock().now()

    def callback(self, msg):
        # Decode JPEG → numpy BGR image
        buf = np.frombuffer(msg.data, dtype=np.uint8)
        frame = cv2.imdecode(buf, cv2.IMREAD_COLOR)
        if frame is None:
            return

        # Run YOLOv8 inference
        results = MODEL(frame, conf=CONF_THRESH, verbose=False)[0]
        annotated = results.plot()   # draws boxes on the frame

        # Count detections per class
        for box in results.boxes:
            cls_id = int(box.cls[0])
            label  = MODEL.names[cls_id]
            conf   = float(box.conf[0])
            self.get_logger().info(f"  {label}: {conf:.2f}")

        # Re-publish annotated frame
        out = CompressedImage()
        out.header = msg.header
        out.format = "jpeg"
        _, buf = cv2.imencode(".jpg", annotated)
        out.data = buf.tobytes()
        self.pub.publish(out)

        # Log FPS every 30 frames
        self.frame_count += 1
        if self.frame_count % 30 == 0:
            dt = (self.get_clock().now() - self.t0).nanoseconds / 1e9
            self.get_logger().info(f"FPS: {self.frame_count / dt:.1f}")

def main():
    rclpy.init()
    rclpy.spin(YoloDetector())

if __name__ == "__main__":
    main()

5. Viewing Results in RViz2

  1. In RViz2, click Add → By topic → /yolo_laptop_vis → Image.
  2. Run the yolo_detector.py script on your laptop.
  3. The Image panel in RViz2 will show annotated frames in near-real-time.
  4. Adjust CONF_THRESH to filter low-confidence detections.
