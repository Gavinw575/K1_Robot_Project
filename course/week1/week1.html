Week 1 — Hardware Overview & First Connection

Learning Objectives
  • Identify the key hardware components of the Booster K1 robot
  • Apply all safety rules before and during robot operation
  • Establish an SSH connection to the robot over Ethernet
  • Run basic Linux navigation commands on the robot
  • Verify a live ROS 2 connection by listing active topics

1. Booster K1 Specifications

The Booster K1 is a full-size humanoid robot designed for research and development. Understanding its hardware capabilities is essential before writing any software.

Component Specification
Degrees of Freedom22 DOF (7 per arm, 6 per leg, 1 waist, 1 head)
Onboard ComputerNVIDIA Jetson Orin NX 16 GB
CameraStereo MIPI camera (head-mounted)
Microphone ArrayNationalChip 6-channel microphone array
Operating SystemUbuntu 22.04 LTS
MiddlewareROS 2 Humble Hawksbill
Network (wired)Gigabit Ethernet — robot IP 192.168.10.102

2. Safety Rules

⚠ Safety First — Read Before Powering On
  1. Damping mode first. Always initialize the robot into damping mode before any other command. In damping mode the joints resist motion with friction but do not actively move — the robot can be physically repositioned safely.
  2. Clear the area. Ensure a 1.5 m radius around the robot is free of people, cables, and obstacles before enabling motion commands.
  3. Emergency stop. Keep one hand on the physical power switch (or a keyboard shortcut mapped to kDamping) at all times during autonomous motion.
  4. Never block joints. Do not grab or obstruct a moving joint — the torque is sufficient to cause injury.
  5. Battery low warning. If the robot announces low battery, return it to the charging stand immediately. Do not run motion commands with a critically low battery.
  6. Two-person rule. When testing new motion code for the first time, always have a second person present who can kill power.

3. Network Setup & SSH Connection

The K1 communicates over a wired Ethernet connection. Connect your laptop directly to the robot's Ethernet port (or through a switch on the same subnet) and configure your laptop's IP to the 192.168.10.x range.

3.1 Configure Your Laptop IP

  1. Open Network Settings on your laptop.
  2. Select the wired Ethernet interface and choose Manual addressing.
  3. Set IP address to 192.168.10.10, subnet mask 255.255.255.0.
  4. Leave the gateway blank (no internet needed for this subnet).
  5. Apply the settings and plug in the Ethernet cable.

3.2 SSH Into the Robot

Use the following command to open a shell on the robot's Jetson:

# SSH into the K1 robot (password: 123456)
ssh booster@192.168.10.102

# Ping the robot before SSH to confirm network reachability
ping -c 4 192.168.10.102

# Expected output — round-trip times should be under 1 ms on direct Ethernet
# PING 192.168.10.102 ... 4 packets transmitted, 4 received, 0% packet loss

4. Basic Linux Navigation

Once logged in, use these commands to explore the robot's file system:

# Show current directory
pwd

# List files with details
ls -la

# Change to the Booster SDK directory
cd ~/booster_robotics_sdk

# Show disk usage
df -h

# Show running processes
top

# Check system info
uname -a

5. Verifying ROS 2 Connection

The K1 runs a ROS 2 Humble stack. You can inspect it from either the robot's own terminal or from your laptop (once FastDDS is configured — covered in Week 2). From the robot: 

# Source ROS 2 environment (add to ~/.bashrc if not already there)
source /opt/ros/humble/setup.bash

# List all active topics
ros2 topic list

# Expected topics include (partial list):
# /booster_video_stream
# /low_state
# /robot_interface/imu
# /tf
# /joint_states

5.1 Robot LED States

The K1 uses LED indicators to communicate internal state. Observe and document the LED color and pattern for each state:

LED State Meaning
Solid greenSystem ready, ROS 2 running
Flashing yellowBooting / initializing
Solid redFault / emergency stop active
Flashing redLow battery warning
BlueDamping mode active
