Week 8 — Autonomous Ball Tracking

Learning Objectives
  • Implement proportional control to close the loop between vision and motion
  • Convert pixel-space bounding box coordinates to robot velocity commands
  • Estimate distance from bounding box area
  • Build a state machine: SEARCHING, TRACKING, APPROACHING, KICKING
  • Tune proportional gains for smooth, stable tracking

1. Proportional Control Theory

A proportional controller computes an output proportional to the current error. For ball tracking, the “error” is the distance between the ball and the image center: 

# Proportional control
# error  = desired_value - current_value
# output = Kp * error

# For yaw (left/right tracking):
# error_yaw = frame_center_x - ball_center_x    (pixels)
# vyaw = Kp_yaw * error_yaw

# For forward speed (approach):
# error_dist = target_area - ball_area  (pixels^2)
# vx = Kp_vx * error_dist
Gain Too High Gain Too Low Gain Just Right
Oscillation / overshoot — robot swings past the ball and corrects back repeatedly Slow response — ball rolls away before robot catches up Smooth convergence — robot centers on ball in 1–2 seconds without oscillation

2. Pixel Space to Robot Commands

The K1 camera outputs frames at 640×480 pixels. The image center is at (320, 240). If the ball is at pixel (bx, by): 

# Frame dimensions (update if camera resolution differs)
FRAME_W = 640
FRAME_H = 480
CENTER_X = FRAME_W // 2   # 320

# Normalize error to [-1, 1]
# Positive error → ball is left of center → turn left (positive vyaw)
def pixel_to_yaw_error(ball_cx: float) -> float:
    return (CENTER_X - ball_cx) / CENTER_X   # [-1, +1]

# Bounding box area → distance proxy
# Large area = close; small area = far
TARGET_AREA = 8000   # pixels^2 — desired "kick distance"

def area_to_vx_error(box_w: float, box_h: float) -> float:
    area = box_w * box_h
    return (area - TARGET_AREA) / TARGET_AREA   # negative = too far away

3. Ball Detection with YOLOv8

from ultralytics import YOLO
import numpy as np

model = YOLO("yolov8n.pt")
BALL_CLASS_ID = 32   # COCO class 32 = sports ball
CONF_THRESH   = 0.45

def detect_ball(frame: np.ndarray):
    """Returns (cx, cy, w, h) of the highest-confidence ball, or None."""
    results = model(frame, conf=CONF_THRESH, classes=[BALL_CLASS_ID],
                    verbose=False)[0]
    if len(results.boxes) == 0:
        return None
    box = results.boxes[0]   # highest confidence first
    x1, y1, x2, y2 = box.xyxy[0].tolist()
    cx = (x1 + x2) / 2
    cy = (y1 + y2) / 2
    w  = x2 - x1
    h  = y2 - y1
    return cx, cy, w, h

4. State Machine

A finite state machine organizes the robot's behavior into discrete states, each with clear entry/exit conditions: 

from enum import Enum, auto

class State(Enum):
    SEARCHING   = auto()   # rotate in place looking for ball
    TRACKING    = auto()   # ball visible; align heading
    APPROACHING = auto()   # heading aligned; walk toward ball
    KICKING     = auto()   # close enough; execute kick motion

SEARCH_VYAW  = 0.3    # rad/s slow search rotation
KP_YAW       = 0.5    # proportional gain for yaw
KP_VX        = 0.0003 # proportional gain for forward speed
ALIGN_TOL    = 0.08   # normalized error; within this → aligned
KICK_AREA    = 12000  # ball bbox area when close enough to kick
LOST_TIMEOUT = 3.0    # seconds without seeing ball → back to SEARCHING

import time

class BallTracker:
    def __init__(self, loco_client):
        self.client = loco_client
        self.state  = State.SEARCHING
        self.last_seen = time.time()

    def update(self, frame: np.ndarray):
        detection = detect_ball(frame)

        # ----- Lost ball timeout -----
        if detection is None:
            if time.time() - self.last_seen > LOST_TIMEOUT:
                self.state = State.SEARCHING
        else:
            self.last_seen = time.time()

        if self.state == State.SEARCHING:
            self._search(detection)
        elif self.state == State.TRACKING:
            self._track(detection)
        elif self.state == State.APPROACHING:
            self._approach(detection)
        elif self.state == State.KICKING:
            self._kick()

    def _search(self, detection):
        if detection:
            self.state = State.TRACKING
            return
        self.client.Move(0, 0, SEARCH_VYAW)

    def _track(self, detection):
        if detection is None:
            return
        cx, cy, w, h = detection
        yaw_err = pixel_to_yaw_error(cx)
        vyaw = KP_YAW * yaw_err
        self.client.Move(0, 0, vyaw)
        if abs(yaw_err) < ALIGN_TOL:
            self.state = State.APPROACHING

    def _approach(self, detection):
        if detection is None:
            return
        cx, cy, w, h = detection
        vx_err = area_to_vx_error(w, h)
        if w * h >= KICK_AREA:
            self.state = State.KICKING
            return
        yaw_err = pixel_to_yaw_error(cx)
        vyaw = KP_YAW * yaw_err * 0.5    # gentle yaw correction while approaching
        vx   = -KP_VX * vx_err
        vx   = max(0.05, min(0.3, vx))  # clamp forward speed
        self.client.Move(vx, 0, vyaw)

    def _kick(self):
        self.client.Move(0, 0, 0)
        print("KICK!")
        # TODO: trigger kick motion via SDK
        time.sleep(2)
        self.state = State.SEARCHING

5. Tuning the Proportional Gains

  1. Start with KP_YAW = 0.1 and KP_VX = 0.0001 (very low).
  2. Place a ball in front of the robot and observe the tracking behavior.
  3. Increase KP_YAW gradually by 0.1 until the robot turns toward the ball promptly without overshooting.
  4. If you see left-right oscillation, reduce KP_YAW by 0.05.
  5. Then increase KP_VX until the robot walks toward the ball at a comfortable speed.
  6. Test by rolling the ball slowly and checking the robot tracks it smoothly.
